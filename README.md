# CyberGuardAI

AI-Powered Cyber Threat Detection & Security Monitoring System.

## Project Overview
CyberGuardAI is a modern cyber security landing page showcasing AI-driven threat detection, real-time monitoring, and intelligent incident response.

## Features
- AI-powered cyber threat detection
- Real-time monitoring dashboard
- Automated incident response
- Premium cyber security branding
- Embedded YouTube demo video

## Run locally
Open `index.html` directly in your browser.

## Files
- `index.html` — main page layout
- `style.css` — styling and responsive design
